# STM32 Custom PCB Project - ASU Racing Team

This project contains the complete hardware design files for the STM32-based Low Voltage controller.

## 📁 Project Structure
- `Layout.png`: 3D or layout overview of the PCB.
- `PCB.png`: Top/Bottom copper routing.
- `Schematic.png`: Schematic diagram of the circuit.
- `STM32_PCB.PcbDoc`: Altium Designer PCB source file.
- `STM32_PCB_Gerber.zip`: Manufacturing Gerber files.
